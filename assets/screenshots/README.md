- `commander.png`, `expedition.png`, `fleet.png`: iPhone 17 Pro simulator, iOS 26.5, 1206 × 2622.

Simulator captures use the system status-bar override for time and battery. Android captures retain the device's actual system chrome. Full-size images are linked from the gallery. The sample snapshot has no active route or missions; those states are deliberately preserved.
