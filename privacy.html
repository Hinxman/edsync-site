Your commander, your connection

Privacy, plainly.

EDSync is designed around your PC and the devices you choose to pair. This page describes the current development version and this website.

Updated 13 September 2026

On your PC and phone

Command Link reads Elite Dangerous journal files from the folder you select and stores the resulting data on your PC. This can include your commander name, locations, ships, transactions and gameplay history. Paired phones receive that information over an encrypted local connection and keep a local cache so you can browse offline.

Pairing uses a short-lived QR code. You can revoke a paired device in Command Link. Revoking access stops future access; it does not remotely erase data already cached on that phone.

Camera and photos

The mobile app uses your camera to scan a pairing code when you choose to pair. If you choose a commander portrait, the selected image is saved on that device for the commander. Portraits are not currently synced through Command Link.

Optional online services

Features that look up systems through EDSM send the requested system name to EDSM. That service also receives ordinary connection information, such as your IP address. These requests are separate from local journal sync. See EDSM’s privacy policy.

Optional Frontier account linking is being prepared. When available, authentication will use Frontier’s sign-in page. This website does not collect Frontier passwords or provide a login form. Frontier’s handling of its services is described in its privacy policy.

Analytics and this website

The current apps do not include advertising trackers or analytics uploads. This static website uses no analytics, advertising cookies, contact forms or third-party fonts. Fonts and screenshots are served with the site.

GitHub hosts this website and its release downloads. GitHub may process IP addresses and request logs to operate and secure those services under the GitHub Privacy Statement.

Support and removal

Support issues on the public GitHub repository are visible to others. Keep pairing codes, credentials and personal journal files out of public reports. You can remove a portrait in the app and revoke paired devices in Command Link. Removing local app data removes the corresponding local cache; desktop uninstall options can retain data, so review those choices if you want to remove it.

For questions about this project, open a support issue without including private information.
